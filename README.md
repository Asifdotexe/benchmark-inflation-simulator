# Benchmark Inflation Simulator

Interactive tool to simulate LLM benchmark score inflation based on retries, tools, and judge leniency.

[Benchmark inflation simulator](public\demo.gif)

## Setup from scratch

1. Install Node.js.
2. Clone repository.
3. Install dependencies:
   ```bash
   npm install
   ```
4. Run dev server:
   ```bash
   npm run dev
   ```
